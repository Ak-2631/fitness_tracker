A high-authority, mission-control style log entry module for the KINETIC Performance OS. This page allows the user to log meals (fueling), tasks (discipline), and workout sets (execution) with industrial precision.

**DESIGN SYSTEM (REQUIRED):**
- Philosophy: Industrial Brutalism / Mission Control Authority.
- Colors: Pure Black (#000000) background, Neon Green (#D0FF00) accent, White (#FFFFFF) text.
- Spacing: Strict 8/16/24/40/64 hierarchy.
- Border Radius: 0px (Absolute corners).
- Typography: Huge 120px italic headers (DAILY OUTPUT style), 11px uppercase tracking-[0.2em] italic labels.
- Components: Thick 80px progress bars with text INSIDE. Zero-radius outlined buttons.

**Page Structure:**
1. Tactical Sidebar (Overview, Analytics, Network, Assets, Settings).
2. Header: "LOG_ENTRY_HUD" (120px, Italic, Black).
3. Sub-status: "READY_FOR_DATA_INPUT // SECTOR-01".
4. Triple Primary Lanes (12-column grid: 4/4/4 split):
   - Lane 1: FUELING_INPUT (Meal registration, calorie logging, macro telemetry).
   - Lane 2: DISCIPLINE_INPUT (Task registration, priority intensity mapping, energy level telemetry).
   - Lane 3: EXECUTION_INPUT (Movement selection, set/rep/volume registration).
5. Footer: "TERMINATE_SESSION" high-chroma neon button sitewide.
6. Real-time Feedback: Neon text prompts indicating "NEURAL_LINK_STABLE" on every successful entry.
